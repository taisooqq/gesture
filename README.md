# 손 제스처

웹캠 앞의 손 모양을 한 창에서 보고, 학습용 영상을 태그별로 저장합니다.

파이썬 **3.14** 를 사용합니다.

## 구조

```text
src/main.py            실행 파일
src/gesture/           동작 클래스
  app.py               창 실행
  config.py            제스처 이름, 명령, 경로
  hand.py              손 영역 분리와 형태 특징
  collector.py         웹캠 촬영
  trainer.py           모델 학습
  smoother.py          흔들린 판정을 걸러 명령을 한 번만 전달
  slides.py            이전 슬라이드 창
  live.py              이전 실시간 인식
  ui.py                인식·등록 창. PySide6
  recorder.py          등록 영상을 줄여 저장
data/                  촬영 이미지와 등록 영상
models/                학습된 모델
```

실행하면 창은 하나만 열리고, 처음 보이는 화면은 등록 탭입니다. 왼쪽에서 녹화하고, 오른쪽 태그를 고릅니다. 인식 탭은 웹캠과 손 판정을 보여 줍니다. Space는 녹화와 저장을 전환하고, 방향키는 태그를 이동합니다.

처음 태그는 마우스포인터 움직임, 좌클릭, 우클릭, 뒤로가기, 앞으로가기, 새로고침, 드래그, 드롭, 무동작입니다. 추가·수정·삭제한 목록은 `data/tags.json`에 저장됩니다. 태그를 지워도 이미 찍은 영상 파일은 남습니다. 저장 파일은 `data/videos/태그/태그_0001.avi` 입니다. 원본 그대로 넣지 않고, 화면 중앙 박스만 잘라 가로 640픽셀, 초당 15장, MJPG로 줄입니다.

등록 탭은 카메라 아래에 저장 영상을 15fps로 재생합니다. 오른쪽 위는 태그, 아래는 선택한 태그의 영상 목록입니다. 영상 삭제도 됩니다. 학습에 이미 쓴 영상은 `학습됨`으로 표시됩니다. 학습 버튼은 저장된 영상으로 모델을 새로 만듭니다. 모델 파일은 `models/model_01.joblib`처럼 학습할 때마다 따로 생기고, 목록에는 그 모델이 학습한 영상 개수가 나옵니다. 목록에서 고른 모델을 인식 탭이 사용합니다.

## 데이터는 사진

등록 탭에서 저장한 영상을 그 탭의 학습 버튼이 사용합니다.

저장되는 범위는 화면 전체가 아닙니다. 가로·세로 약 55% 크기의 중앙 박스만 남깁니다. 얼굴이 파일에 들어가지 않게 하기 위한 영역입니다. 손은 그 박스 안에 두고, 위치·거리·각도를 바꿔 가며 여러 장을 찍습니다. 배경은 단색, 조명은 고정된 상태가 안정적입니다.

파일 이름에 촬영자 ID가 들어갑니다.

```text
data/fist/p1_fist_0001.png
data/palm/p1_palm_0001.png
```

폴더 이름이 정답 라벨입니다. 키 `1` 주먹, `2` 보, `3` 가위, `4` 손가락 1, `5` 엄지입니다. 다른 팀원은 `--person p2` 처럼 ID를 바꿔 같은 방식으로 찍습니다. 과제 기준으로는 한 사람당 클래스마다 50장 이상, 클래스마다 전체 200장 이상을 목표로 합니다.

"손 없음"은 사진 클래스가 아닙니다. 나중에 손 윤곽이 안 잡히면 코드가 직접 손 없음으로 처리합니다.

## 학습 전에 사진을 숫자로 바꿈

모델은 사진 픽셀을 그대로 받지 않습니다. `train` 이 각 PNG에서 손을 찾은 뒤, 형태를 숫자 8개로 바꿉니다. 손이 안 나뉜 사진은 학습에서 빠집니다.

1. 이미지를 YCrCb 색 공간으로 바꾼 뒤, 피부색 범위만 남깁니다.
2. 작은 잡음은 지우고, 손 영역 구멍은 메웁니다.
3. 남은 영역 중 가장 큰 윤곽을 손으로 봅니다.
4. 그 윤곽에서 아래 8개를 계산합니다.


| 특징            | 의미                               |
| ------------- | -------------------------------- |
| area_ratio    | 박스 대비 손 면적                       |
| aspect        | 가로가 세로보다 얼마나 긴지                  |
| solidity      | 오목한 곳이 얼마나 없는지. 주먹은 높고 보자기는 낮습니다 |
| circularity   | 원형에 가까운 정도                       |
| defects       | 손가락 사이 골의 개수                     |
| hu1, hu2, hu3 | 윤곽의 대략적인 형태                      |


같은 변환을 실시간 데모에서도 그대로 씁니다. 학습 때와 실행 때의 입력이 같아야 하기 때문입니다.

## 모델

분류기는 scikit-learn의 **랜덤포레스트**입니다. 트리 200개를 쓰고, 그 앞에 특징 크기를 맞추는 `StandardScaler` 가 붙어 있습니다. 이미지 전체를 학습하는 CNN 같은 딥러닝 모델은 쓰지 않습니다.

랜덤포레스트는 숫자 8개로 "이 손은 주먹에 가깝다"처럼 클래스 확률을 냅니다. 나무가 여러 개인 이유는, 한 장의 기준에 과하게 기대지 않고 여러 기준의 표를 모으기 위해서입니다.

학습 순서는 다음과 같습니다.

1. `data/` 의 PNG를 모두 읽어 특징 8개와 폴더 라벨, 파일명의 촬영자 ID를 모읍니다.
2. 촬영자가 두 명 이상이면 GroupKFold 로 점수를 먼저 냅니다. 한 사람의 사진을 통째로 시험 세트에 넣어, 처음 보는 손에서도 맞는지 확인합니다. 촬영자가 한 명이면 이 점수는 생략합니다.
3. 확인이 끝나면 모은 사진 전체로 다시 학습합니다.
4. 결과를 `models/gesture.joblib` 에 저장합니다. 파일 안에는 스케일러, 랜덤포레스트, 클래스 이름 순서가 함께 들어 있습니다.

## 실시간에서 명령이 나가는 조건

`demo` 는 저장된 모델을 불러 웹캠 프레임마다 같은 특징을 뽑고 클래스 확률을 받습니다. 확률이 프레임마다 튀므로, 직전 확률과 섞어 부드럽게 만든 뒤(EMA) 가장 높은 클래스를 고릅니다.

확신이 0.65 미만이거나, 같은 모양이 8프레임 미만으로 짧으면 명령을 보내지 않습니다. 조건을 통과해도 그 손 모양에 대해 명령은 한 번만 나갑니다. 주먹을 계속 쥐고 있어도 슬라이드가 연달아 넘어가지 않습니다. 손을 내렸다가 다시 보여 주면 다음 명령이 나갈 수 있습니다.

## 실행

파이썬 3.14 콘다 환경을 받은 상태에서의 순서입니다. Windows는 Anaconda Prompt, macOS·Linux는 터미널에서 진행합니다.

1. 받은 환경을 켭니다. `환경이름`은 전달받은 이름으로 바꿉니다.

```text
conda activate 환경이름
python --version
```

`Python 3.14`로 나오면 다음으로 넘어갑니다.

2. 이 저장소를 받은 프로젝트 폴더로 이동합니다. 아래 경로는 예시이고, 실제 받은 위치로 바꿉니다.

```text
cd C:\Users\user1\soo\project\gesture
```

3. 라이브러리를 설치합니다. `requirements.txt`에 있는 것은 다섯 가지입니다.

- `opencv-python`: 웹캠, PNG 저장·읽기, 피부색 마스크와 손 윤곽. 코드에서는 `cv2`로 부릅니다.
- `numpy`: 특징 숫자 배열
- `scikit-learn`: 스케일러와 랜덤포레스트
- `joblib`: `models/gesture.joblib` 저장과 불러오기
- `PySide6`: 창과 탭. Qt의 공식 파이썬 라이브러리입니다.

```text
python -m pip install -r requirements.txt
```

4. 실행 파일이 있는 `src`로 이동한 뒤 창을 엽니다. `main.py`가 같은 폴더의 `gesture` 패키지를 불러오므로, 이 명령은 `src` 안에서 실행합니다.

```text
cd src
python main.py
```

창 하나가 열리고 등록 탭이 먼저 나옵니다. 녹화, 저장, 학습은 그 창에서 합니다. Space로 녹화와 저장을 전환하고, 방향키로 태그를 이동합니다. 카메라 번호는 `python main.py --camera 1`처럼 바꿉니다. 창을 닫으면 종료되고, 녹화 중이었다면 그때까지 찍은 영상을 저장합니다.
